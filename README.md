# kyka-zavr.github.io

Визитка: чёрно-белая, без JavaScript. Ссылки на TikTok, Telegram и GitHub.

Сайт: https://kyka-zavr.github.io

Файлы:

- `index.html` — страница
- `style.css` — стиль (чёрный фон, белый текст, инверсия при наведении)
- `mark.svg` — знак ∞ (из Infinity-hyperland)
- `favicon.svg` — иконка

## Публикация

GitHub Pages, ветка `main`, корень репозитория. Достаточно запушить изменения:

```sh
git add .
git commit -m "Site: ..."
git push
```

Через минуту страница обновится.
